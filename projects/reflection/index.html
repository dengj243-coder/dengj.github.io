Midterm Reflection

Exploring My Design Journey

Reflecting on the projects that I have done till date, I see that I am inclined towards creating layouts that are clean, typography that is bold, and elements that are interactive and enhance the interactivity of the website. I love working with different types of dynamic effects, color palettes, and interaction possibilities of the user with the web page. Although there is an individual theme of each project that I have worked on, the common goal for all these projects is that I try to create a visually appealing experience for the user and not just give out a list of information. The style of the projects vary from being organized and well thought through to being playful and experimental. This has helped me master the use of HTML and CSS for layout, position and animations.
